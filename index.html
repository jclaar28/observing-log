Observing site

Set your latitude to mark catalog objects that never rise high enough to observe.

North is positive, south is negative. Leave empty to turn the filter off.

East is positive, west is negative. Used for tonight's times. Leave empty to estimate it from your time zone.

An object counts as out of reach if it never climbs above this. Use 0 for the true horizon, or more to allow for trees and haze.

How high trees or buildings reach in each direction, in degrees. Objects behind them don't count as up. Leave at 0 for an open horizon.

Gear

Individual pieces of equipment. Pick any combination when you log an observation. Filters are suggested in the Filter field.

    Focal length and sensor size let object pages show how a target fits your camera.
